# Data Structures and Algorithms (DSA)

Welcome to my Data Structures and Algorithms practice repository. This repository contains my daily practice code, solutions to various algorithmic problems, and interview preparation materials.

## 📂 Repository Structure

Based on the folders in this repository, here is a breakdown of the contents:

### Data Structures & Core Algorithms
*   **BinarySearch**: Implementations and problems related to Binary Search.
*   **DP**: Dynamic Programming problems, memoization, and tabulation solutions.
*   **GreedyAlgo**: Greedy algorithms and related practice.
*   **LinkedList**: Singly, Doubly, and Circular Linked List concepts and challenges.
*   **Stack**: Stack data structure implementations and use-cases.
*   **Tree**: Binary Trees, BSTs, and other tree-based problems.

### Coding Platforms
*   **LeetCode / leetcode-problems**: My solutions to various LeetCode problems.
*   **Noukri**: Coding problems and solutions from Naukri (Coding Ninjas).
*   **TCS**: TCS-specific interview prep and coding questions.
*   **campx**: Practice problems from CampX.
*   **Exercism** : Coding from Exercism plateform

### Daily Progress & Practice
*   **Day1, Day2, Day4, Day5...**: Daily coding logs and specific day-to-day challenges.
*   **ExamProb, QSPapers, QS_Solution**: Exam problems, question papers, and their respective solutions.
*   **Practice & DSAQUESTIONS**: General practice problems and miscellaneous DSA questions.

## 🚀 How to Use

Navigate to the respective topic or platform folder to find the source code. Most folders contain standalone scripts or projects focusing on a specific problem or concept.
